# 1.4.3

Promotes the user-accepted 1.4.3-rc5 to Live. Live retains its logo, grey header, manifest and cloud Worker configuration. Deployment does not restore or replace user data.

Includes guarded enrichment import, compressed and verified local storage with recovery safeguards, separate Testbed local storage, scoped offline caches, the final-shutdown Download/Cancel backup dialogue, and the passage analytics table.

Analytics shows all metrics including nights on board, sortable and filterable columns, year/month/day and date-range filters, filtered totals, and a frozen Date column and headings. The Settings grid constrains the table so horizontal scrolling works on iPad. Date filters select passage start dates; the nights total deduplicates shared completed nights.

Validation: accepted Testbed release checks; Live syntax/assets, DOM/storage/enrichment tests, Safari-engine table and entry/layout checks, and service-worker upgrade/offline persistence checks.
